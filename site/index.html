USB Terminal MCP

Turn an ESP32-S3 into a USB keyboard + terminal that AI agents can use on any computer.

You need: an ESP32-S3 board with native USB (e.g. ESP32-S3-DevKitC-1), a USB cable, and Chrome or Edge on a computer.

  1. Plug the board's UART (or "COM") USB port into this computer.
  2. Pick your board and click Connect, then Install:
    Your browser can't flash devices. Use Chrome or Edge on a computer. This page must be opened over HTTPS.

    Not sure? Look for "R8" in the module's name, or just try the first button. If the board keeps rebooting, use the second.

  3. When asked, enter your Wi-Fi (2.4 GHz). It's sent to the board over the USB cable and stored only there.
  4. Click Visit device. The setup page shows the command to connect your agent, e.g. claude mcp add --transport http usb-terminal http://<ip>/mcp --header "Authorization: Bearer <token>"
  5. Plug the board's USB-OTG port into the computer you want the agent to control. Done.

No Chrome? Flash the .bin from the releases with any ESP flasher at offset 0. On first boot, join the usb-terminal-XXXX Wi-Fi network from your phone and the setup page opens.

On the device: press BOOT to show the access token on the setup page for 2 minutes. Hold it for 5 seconds to factory reset.
